# Goutam Agrawal — Portfolio

Personal portfolio with liquid glass styling, project filters, and expandable project details.

## Run locally

Serve this directory with any static server, for example:

```bash
python3 -m http.server 8000
```

## GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, then **main** and **/(root)**.

## Edit

- `index.html`: introduction, experience, education, achievements, and contact.
- `app.js`: project content and filtering.
- `style.css`: responsive layout and liquid glass effects.
